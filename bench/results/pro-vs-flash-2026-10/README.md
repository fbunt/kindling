# pro-vs-flash, 2026-10: the run behind the paper's core-tier numbers

Gemini 3.1 Pro Preview vs Gemini 3.8 Flash on the 25 core questions, 5 trials each,
interleaved (seed 0). Run 2026-09-29 at commit `e225059`; graded by grader sha
`ee57b57a09b8` (`GRADER_VERSION` 9); adjudicated, triaged and hand-audited through
2026-10-19. Scoring rules: [decision 0004](../../../docs/decisions/0004-score-the-bench-strictly-with-rules-fixed-before-grading.md).

| | 3.1 Pro | 3.8 Flash |
|---|---|---|
| strict accuracy | 125/125 | 122/125 |
| executability | 125/125 | 124/125 |
| pass^5 (macro) | 100% | 92% |
| judge-human agreement (blind 10% audit) | 13/13 | 13/13 |

Paired difference +2.4 pp, 95% CI [0.0, +6.4], sign-flip p = 0.51: the core tier does not
separate the models. Flash's fails: A06 trials 0 and 1 (`question_ambiguity`: a hedge between
two readings of "burned-pixel rows") and T02 trial 1 (`empty_response`).

## Files

- `<model>/report.md`, `compare-*.md`: the reports as generated by `bench report` / `compare`.
- `<model>/adjudication.json`: hand verdicts on every trial the grader flagged for review,
  with the reason and the context each was decided on.
- `<model>/audit.json`: the seeded 10% sample with blind hand verdicts.
- `<model>/triage.json`: failure modes of the failed trials.
- `<model>/run_meta.json`: the run fingerprint (git sha, prompt and question shas, parquet
  identity, SDK/Polars/worker-image versions, sandbox settings).
- `ground_truth/29d168015b13.json`: the reference answers for this parquet identity.
- `traces.tar.gz`: the whole run directory as graded: all 250 traces (response, every query
  and result, per-call tokens and latency, extraction and verdict) plus the files above.

## Re-running the reports

The tools read run directories under `.bench-runs/`. From a checkout of the commit that added
this archive (later question rewording changes `question_sha`):

```bash
tar -xzf bench/results/pro-vs-flash-2026-10/traces.tar.gz -C .bench-runs
uv run python -m bench report --run-dir .bench-runs/pro-vs-flash
uv run python -m bench compare .bench-runs/pro-vs-flash
```

This overwrites any existing `.bench-runs/pro-vs-flash`. Neither command calls an API.
